# 🎅 Santa

Private, offline dictation for English, Hindi, Arabic, Hinglish and Bengali,
built on Whisper Local and running entirely on your Mac.

* **Start the window:** Spotlight → "Santa" (or `santa-app/Santa.command`)
* **Type into any app:** `santa-app/Santa Dictation (hotkey).command`, then hold **Fn+Ctrl**, speak, release
* **Install / update:** `santa-app/Install Santa.command` · **Uninstall:** `santa-app/Uninstall Santa.command`
