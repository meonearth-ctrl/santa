          Set up your iPhone

          Your iPhone and this Mac must be on the same Wi-Fi. Speech is sent encrypted to this Mac and recognised here — nothing goes to the internet, and nothing is reachable from outside your home network.

          1 · Trust this Mac (once)

          The iPhone only allows the microphone on secure pages, so it needs this Mac's own certificate. It can only vouch for this Mac on your home network, never for real websites.

          Finder opens with the file selected: right-click › Share › AirDrop › your iPhone.

          1. On the iPhone, allow the download, then open Settings › Profile Downloaded › Install.
          2. Settings › General › About › Certificate Trust Settings › switch on Santa local CA.

          3 · Put Santa on the Home Screen

          In Safari tap Share › Add to Home Screen. The Home Screen app keeps its own sign-in, so the first time you open it, press Show pairing code again and type the new code.

          On the phone, Share… sends the text to any app (WhatsApp, Mail, Notes…), and Copy puts it on the clipboard.

          4 · Optional: dictate from anywhere with a Shortcut

          An iOS Shortcut can record, send the audio to Santa and put the text on your clipboard — start it with Back Tap (Settings › Accessibility › Touch › Back Tap) or Siri.

          Shown only once. Keep it private — anyone with it can use Santa on your Wi-Fi. Remove it below to switch it off.

          1. Shortcuts app › + › add Record Audio (Audio Quality: Normal, Start Recording: Immediately).
          2. Add Get Contents of URL: URL , Method POST, Headers: Authorization = Bearer <the key above>, Request Body File = Recorded Audio.
          3. Add Copy to Clipboard (Contents of URL), then optionally Show Notification.
          4. Name it Santa. Settings › Accessibility › Touch › Back Tap › Double Tap › Santa.
